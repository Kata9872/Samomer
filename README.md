# Самомер

Локальное desktop-приложение для отслеживания привычек, целей и количественных показателей.

## Возможности

- Создание трекеров пяти типов: выполнение, количество, длительность, число и оценка.
- Быстрый ввод значений с постоянной историей в SQLite.
- Процент выполнения, серия выполненных дней и график динамики.

## Архитектура

Tkinter → локальная бизнес-логика → SQLModel → SQLite. Приложение работает полностью офлайн, без сервера и сети. Недельный прогресс сравнивает сумму за неделю с дневной целью, умноженной на 7.

## Установка

Скачайте файлы из репозитория, например через **Code → Download ZIP**, и откройте терминал в папке проекта. Нужен Python 3.10 или новее с Tkinter.

```shell
python -m venv .venv
```

Активируйте окружение: Windows — `.venv\Scripts\activate`, Linux/macOS — `source .venv/bin/activate`. Затем установите зависимости:

```shell
pip install -r requirements.txt
```

## Запуск

```shell
python main.py
```

## Запуск готовой версии

Скачайте `Samomer.exe` из `dist/` на компьютер с Windows и запустите двойным кликом. Терминал и установленный Python не нужны. Приложение работает офлайн; разместите `.exe` в папке, доступной для записи.

Чтобы собрать `.exe` самостоятельно на Windows с установленным Python и Tcl/Tk, выполните `pip install -r requirements.txt`, затем:

```shell
pyinstaller --onefile --windowed --name Samomer main.py
```

## Данные

Трекеры и история хранятся локально в `trackall.db` рядом с приложением или `Samomer.exe`. Файл создаётся автоматически при первом запуске. При переносе `.exe` перенесите вместе с ним `trackall.db`, если хотите сохранить данные.
