# Самомер

Учебный MVP для отслеживания привычек, целей и личных показателей.

## Возможности

- Создание трекеров пяти типов: выполнение (`boolean`), количество (`counter`), длительность (`duration`), числовое значение (`numeric`) и оценка по шкале (`scale`).
- Быстрый ввод значений и постоянное хранение истории в SQLite.
- Просмотр процента выполнения, дневной серии (streak), истории и графика Chart.js.

Цель задаётся на день или неделю. Значения суммируются; неделя начинается в понедельник. Приложение работает для одного пользователя без регистрации.

## Скачивание и запуск

Нужен Python 3.10 или новее. Для установки зависимостей и загрузки Tailwind CSS и Chart.js с CDN нужен доступ к интернету.

1. Откройте [репозиторий проекта](https://github.com/USERNAME/REPOSITORY). **Это ссылка-шаблон: замените `USERNAME` и `REPOSITORY` на свои значения также в DOCX-отчёте.**
2. Нажмите **Code → Download ZIP** и распакуйте архив.
3. Откройте терминал в папке, где находятся `main.py` и `requirements.txt`. Если проект находится в подпапке `Samomer`, перейдите в неё.
4. Установите зависимости:

   ```shell
   python -m pip install -r requirements.txt
   ```

5. Запустите приложение:

   ```shell
   python -m uvicorn main:app --reload
   ```

6. Откройте http://127.0.0.1:8000/. Документация API доступна по адресу http://127.0.0.1:8000/docs.

Оставьте терминал открытым во время работы. Для остановки сервера нажмите **Ctrl+C**. В Windows, если Python запускается командой `py`, используйте её вместо `python`.

## Первый результат

Нажмите **Создать трекер** и укажите: название «Вода», тип `counter`, цель `8`, единицу «стаканов», период `daily`. Нажмите **Создать**, затем пять раз **+1** на карточке: результат станет 5 / 8, выполнение — 62,5%. Кнопка **Статистика** открывает историю и график.

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Сервер FastAPI, API и расчёт статистики |
| `models.py` | Модели SQLModel и валидация данных |
| `index.html` | Интерфейс: HTML, Tailwind CSS, JavaScript и Chart.js |
| `requirements.txt` | Зависимости приложения |
| `Отчет-реализация.docx` | Пошаговая инструкция со скриншотами |
| PDF-документы | Исходные требования и бизнес-гипотеза |

Файл `samomer.db` создаётся автоматически в папке проекта при первом запуске и хранит данные после перезапуска. Не удаляйте его, если хотите сохранить историю. `.gitignore` исключает базу, кеш Python и локальные служебные файлы из Git.
